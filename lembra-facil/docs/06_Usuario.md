# 📘 Manual do Usuário -- Lembra Fácil

## 📌 1. Visão Geral

O **Lembra Fácil** é um aplicativo Android criado para ajudar pessoas
com 60+ anos a lembrar tarefas importantes de forma simples, clara e
acessível.

O app foi pensado para rotinas com tarefas recorrentes
(mensais/semanais) e também tarefas únicas, com foco em:

-   Interface minimalista
-   Botões grandes
-   Poucas opções por tela
-   Fluxo direto e previsível

------------------------------------------------------------------------

## 🏠 2. Tela Principal -- Hoje

### 🎯 Objetivo

Exibir **somente** as tarefas do dia atual, permitindo ações rápidas.

### 📋 O que aparece nesta tela

-   Nome do aplicativo
-   Data atual
-   Lista de tarefas do dia
-   Botões:
    -   ✅ **Feito**
    -   ⏰ **Mais tarde**
-   Informação de próxima tarefa futura (rodapé)

------------------------------------------------------------------------

### ✅ Botão "Feito"

Ao tocar:

1.  A tarefa é marcada como concluída.
2.  O status visual muda para indicar conclusão (ex: cor verde e ícone
    ✔).
3.  Se a tarefa for recorrente:
    -   O aplicativo cria automaticamente a próxima ocorrência.
4.  A tarefa pode sair da lista do dia após atualização.

Quando usar:

-   Sempre que terminar a tarefa.

------------------------------------------------------------------------

### ⏰ Botão "Mais tarde"

Ao tocar:

1.  A tarefa é adiada.
2.  O aplicativo agenda nova exibição:
    -   Algumas horas depois **ou**
    -   Para o dia seguinte (regra definida internamente).
3.  A tarefa pode sair temporariamente da lista do dia.

Quando usar:

-   Se você não puder fazer a tarefa naquele momento.

------------------------------------------------------------------------

### 🎨 Indicadores Visuais

-   🟢 Verde → Tarefa concluída\
-   🟠 Laranja → Tarefa adiada\
-   ⚪ Normal → Tarefa pendente

------------------------------------------------------------------------

## 📂 3. Tela -- Tarefas

### 🎯 Objetivo

Gerenciar todas as tarefas cadastradas, inclusive futuras.

### 📋 O que aparece nesta tela

-   Lista completa de tarefas
-   Frequência (ex: semanal, mensal)
-   Botão ➕ **Nova Tarefa**
-   Menu (⋮) em cada tarefa com opções:
    -   ✏️ Editar
    -   🗑️ Excluir

------------------------------------------------------------------------

### ➕ Nova Tarefa

Abre a tela de cadastro para criar uma nova tarefa.

------------------------------------------------------------------------

### ✏️ Editar

Permite alterar:

-   Nome
-   Frequência
-   Data inicial
-   Categoria

------------------------------------------------------------------------

### 🗑️ Excluir

Ao tocar:

1.  O app pergunta: \> "Deseja realmente excluir esta tarefa?"
2.  Se confirmar:
    -   A tarefa é removida permanentemente
    -   As ocorrências futuras também são removidas

⚠ Atenção: essa ação não pode ser desfeita.

------------------------------------------------------------------------

## 📝 4. Tela -- Nova / Editar Tarefa

### 🏷 Nome da Tarefa (obrigatório)

Exemplos:

-   Tomar remédio
-   Pagar conta de luz
-   Fazer exercícios

------------------------------------------------------------------------

### 🔁 Frequência

Escolha como a tarefa se repete:

-   Uma vez
-   Semanal
-   Mensal

------------------------------------------------------------------------

### 📅 Data Inicial

Define quando a tarefa começa.

Exemplos:

-   Hoje
-   Próxima segunda-feira
-   Dia 5 do mês

------------------------------------------------------------------------

### 🗂 Categoria (opcional)

Exemplos:

-   Saúde
-   Financeiro
-   Exercícios
-   Pessoal
-   Outros

------------------------------------------------------------------------

### 💾 Salvar

-   Registra a tarefa
-   Cria a primeira ocorrência (se recorrente)
-   Retorna para a tela anterior

------------------------------------------------------------------------

### ❌ Cancelar

Fecha sem salvar alterações.

------------------------------------------------------------------------

## 🔔 5. Notificações

O aplicativo envia alertas quando:

-   Uma tarefa estiver próxima do horário definido
-   Uma tarefa estiver vencida

A notificação permite:

-   Abrir o aplicativo diretamente

Funcionalidades futuras possíveis:

-   Marcar como concluída pela notificação

------------------------------------------------------------------------

## 🔄 6. Fluxo de Uso (Resumo)

1.  Abrir o aplicativo
2.  Ver tarefas na tela **Hoje**
3.  Realizar uma ação:
    -   ✅ Feito
    -   ⏰ Mais tarde
4.  Para criar ou alterar tarefas:
    -   Abrir a tela **Tarefas**
    -   Criar, editar ou excluir
5.  Receber notificações e confirmar tarefas

------------------------------------------------------------------------

## ✅ 7. Público-Alvo

O Lembra Fácil foi desenvolvido para:

-   Pessoas com 60+ anos
-   Usuários que preferem simplicidade
-   Rotinas com tarefas recorrentes
-   Pessoas que precisam de lembretes claros e diretos
